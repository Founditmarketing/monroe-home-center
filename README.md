# Monroe Home Center | Industrial Luxury Redesign

A high-octane, industrial luxury redesign of a real estate platform with cinematic visuals, glass-morphism UI, and real-time inventory management.

## Deployment

### Deploy to Vercel

The easiest way to deploy your project is to use the [Vercel Platform](https://vercel.com/new).

1.  **Push your code to a Git repository** (GitHub, GitLab, or Bitbucket).
2.  **Import your project** into Vercel.
3.  **Configure Environment Variables**:
    -   Add `GEMINI_API_KEY` to your Vercel project settings.
4.  **Deploy**: Vercel will automatically detect Vite and deploy your site.

### Preview Locally

**Prerequisites:** Node.js installed on your machine.

1.  **Install dependencies:**
    ```bash
    npm install
    ```
2.  **Set Environment Variables:**
    Create a `.env.local` file and add:
    ```
    GEMINI_API_KEY=your_api_key_here
    ```
3.  **Run the development server:**
    ```bash
    npm run dev
    ```
4.  **Build for production:**
    ```bash
    npm run build
    ```
